# Oberfläche „Bühne“ Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Die QML-Oberfläche der App durch die „Bühne“ ersetzen: ein Wallpaper live fensterfüllend, schwebende Leiste unten, Felder wachsen aus der Leiste nach oben, Ambient-Rahmen, rahmenloses Fenster.

**Architecture:** Python-Backend (`app/lwe/engine.py`, Kontext-Objekt `lwe`) bleibt; es bekommt `hidden`, `applyTarget` und Sortierung über `order`, und verliert das Theme-System. Die QML-Seite (`app/qml/`) wird neu aufgebaut aus kleinen Dateien: `Main.qml` (Fenster, Rahmen, Tastatur), `Stage.qml` (Live-Vorschau mit Überblendung), `Bar.qml`, `Tray.qml` (Feld-Container) und je einer Datei pro Feld. `Preview.qml`, `Toasts.qml`, `Toggle.qml`, `IconButton.qml`, `Icon.qml` bleiben und werden auf das neue `Theme.qml` umgestellt.

**Tech Stack:** Python 3 + PySide6 6.11, Qt Quick / QtQuick.Effects (MultiEffect), pytest 9 mit `QT_QPA_PLATFORM=offscreen`.

**Spec:** `docs/superpowers/specs/2026-11-17-ui-buehne-design.md` (lesen, bevor du anfängst). Prototyp zum Vergleichen: `.superpowers/brainstorm/23503-1794940491/content/prototyp-v5.html` (Rahmen „Ambient“, Icons „Phosphor Duo“) – im Browser öffnen, Werte (Radien, Abstände, Dauern) daraus übernehmen.

## Global Constraints

- Farben nur Schwarz/Weiß; Ausnahmen: Grün `#7dffb2` für „läuft“, Rot `#ff5c7a` fürs Favoriten-Herz, Rot `#ff4d5e` für Schließen-Hover. **Kein Violett/Lila.**
- Animationen nur Deckkraft, Position, Größe; Dauer 80–450 ms; Kurve `Easing.OutCubic`. Knöpfe skalieren beim Drücken auf 0.9.
- Bühnen-`Preview`: `renderScale` 0.6, `fps` = `lwe.settings.fps`, `running` nur wenn `win.visible && win.visibility !== Window.Minimized && Qt.application.state === Qt.ApplicationActive`.
- Höchstens zwei `Preview`-Instanzen gleichzeitig (Überblendung), die alte wird danach entladen.
- Ambient-Rahmen: 9 px, weichgezeichnetes **Vorschaubild** (`thumb`), nie der Live-Shader.
- Schriften: Inter Tight (Text), JetBrains Mono (Zahlen/Meta), mitgeliefert unter `app/qml/fonts/` (OFL).
- Icons: Phosphor Duotone (MIT), nur die genutzten SVGs unter `app/qml/icons/`.
- Texte auf Deutsch, wie im Prototyp.
- Desktop-Plugin (`plugin/`), Panel-Widget (`plasmoid/`), Playlist-Logik und Import-Logik nicht ändern.
- Tests laufen mit: `cd ~/Projekte/fedorama && QT_QPA_PLATFORM=offscreen python3 -m pytest tests -q`

## Review Focus

- **Alle bis auf eins ausgeblendet:** Das letzte sichtbare Wallpaper lässt sich nicht ausblenden (Knopf deaktiviert, `toggleHidden` lehnt ab) → Test in Task 1.
- **Startbild:** Die Bühne startet beim laufenden Wallpaper des ersten Monitors; ist es ausgeblendet, beim ersten sichtbaren → Test in Task 4 (`test_stage_start_index`).
- **`applyTarget` zeigt auf abgesteckten Monitor:** „Anwenden“ setzt dann auf alle Monitore und meldet das per Toast, statt nichts zu tun → Test in Task 1.
- **Import ohne Vorschaubild:** Rahmen und Streifen zeigen eine dunkle Fläche (`#0a0a0a`) statt eines Fehlers/leeren Bildes → Prüfung in Task 4/6 (Smoke-Test lädt Eintrag mit `thumb: ""`).
- **Kleinstes Fenster (820×540):** Leiste überlappt nicht; Name kürzt mit „…“; Felder passen in die Höhe (max. `win.height - 160`) → Screenshot-Prüfung in Task 9.
